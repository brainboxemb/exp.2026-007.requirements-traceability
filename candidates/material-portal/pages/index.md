# Engineering documentation portal

This portal is an Experiment 007 view over the same engineering knowledge used
for traceability.

It is deliberately **not** a second engineering source.

Use the portal for:

- [Engineering explorer](explorer.md) — keep architecture/relationship context
  visible while inspecting one engineering object;
- [Object index](objects/index.md) — browse generated use cases, requirements,
  architecture elements and verification cases;
- [Architecture book](book.md) — return to the coherent linear engineering
  narrative.

The object pages and explorer data are generated from Sphinx-Needs
`needs.json`.
